# LegacyCrafting

LegacyCrafting is a client-side Fabric mod for Minecraft Java Edition 26.2. It
is building toward a fast, category-driven crafting interface inspired by the
usability of Minecraft Legacy Console Edition.

The project is an independent implementation and does not include code,
textures, or other assets from Legacy4J or Minecraft Legacy Console Edition.

## Development status

The mod is under active development. See the repository history for completed
milestones.

## Building

Java 25 is required.

```sh
./gradlew build
```

Build artifacts are written to `build/libs/`.
